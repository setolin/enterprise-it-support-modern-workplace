# Access Matrix

| Access profile | Base access | Additional access | Privileged? | Approval |
|---|---|---|---|---|
| Standard-User | Microsoft 365 core services, department workspace | None by default | No | Line manager |
| Data-Analyst | Data & Analytics workspace | Approved analytics application | No | Data Manager |
| Data-Manager | Data & Analytics workspace | Data administration workspace | No | Operations Director |
| Manager | Department workspace | Manager reporting workspace | No | Operations Director |
| Executive | Executive workspace | Approved company reporting | No | Operations Director |
| Service-Desk-Analyst | Core services, service desk workspace | Endpoint support tools | No | Systems Engineer |
| Privileged-Engineer | Core services, engineering workspace | Approved administrative roles | Yes | Operations Director + access review |
| Finance-User | Finance & People workspace | Finance application | No | Finance lead |
| Quality-Manager | Quality & Regulatory workspace | Quality evidence workspace | No | Operations Director |
| Commercial-User | Commercial workspace | CRM and proposals | No | Commercial lead |

The matrix is a design control, not evidence that cloud permissions have been provisioned.
