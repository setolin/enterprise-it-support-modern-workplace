# Project Charter

## Project

**Enterprise IT Support & Modern Workplace — Applied Technical Case Study**

## Owner

Alex S Beirigo, independent lab designer and implementer.

## Purpose

Create a reproducible, evidence-led laboratory that demonstrates practical IT support and modern workplace operations for a 50-user UK organisation.

## Business problem

The fictional organisation needs a coherent way to manage identities, Windows endpoints, access requests, incidents, onboarding and offboarding. Inconsistent processes create avoidable access risk, slow diagnosis and poor visibility of service quality.

## Objectives

1. Define an operating model that connects identity, endpoint, service desk and automation controls.
2. Build locally executable, safe PowerShell support tooling.
3. Reproduce ten realistic support cases with diagnosis, evidence, resolution and validation.
4. Document cloud features honestly where tenant access or licensing is unavailable.
5. Produce an interview-ready repository that can be explained and verified.

## Success criteria

- Every claim is labelled as implemented, simulated or documented.
- Scripts have help, validation, logging, error handling and tests where appropriate.
- Ten complete support cases are reproducible from sanitised data.
- Documentation links decisions to risks, requirements and evidence.
- No secrets, real customer data or unsupported commercial claims are present.

## Constraints

- No paid licence or external service will be purchased.
- No external publication will occur without explicit authorisation.
- Cloud implementation depends on available tenant permissions and licensing.
- Lab measurements must be reported as lab results only.
