# KB-MAJOR-INCIDENT-001 — Multi-user Service Outage

**Owner:** Alex S Beirigo  
**Status:** Simulated major-incident procedure

Correlate users, services and start times before changing individual accounts. Assign an incident lead, maintain a timestamped timeline and issue concise user updates. Separate confirmed facts, hypotheses and next actions.

Validate recovery with several affected users. Record follow-up actions and create a problem record when the underlying cause requires investigation.
