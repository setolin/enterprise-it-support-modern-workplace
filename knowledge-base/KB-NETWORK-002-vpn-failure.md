# KB-NETWORK-002 — VPN Connection Failure

**Owner:** Alex S Beirigo  
**Status:** Simulated VPN workflow

Confirm public connectivity, exact error and time. Separate client-profile, authentication, endpoint and gateway hypotheses. Review only sanitised client logs. Do not weaken firewall or MFA controls.

Validate access to an approved internal test resource. Escalate gateway failure, certificate issues or multiple affected users.
