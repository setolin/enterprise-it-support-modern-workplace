# KB-IDENTITY-003 — Unexpected Resource Access

**Owner:** Alex S Beirigo  
**Status:** Simulated support procedure

Compare effective group membership with the access matrix and the most recent approved joiner/mover request. Remove unapproved access through groups rather than ad-hoc direct permissions. Preserve a before/after record and request manager validation.

Escalate privileged, sensitive or unexplained access to the Systems Engineer.
