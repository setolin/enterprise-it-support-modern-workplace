# KB-IDENTITY-001 — Account Lockout

**Owner:** Alex S Beirigo  
**Status:** Simulated support procedure

## Symptoms

The user receives an account-lock message or repeated sign-in failures.

## Procedure

1. Verify the fictional user identity and business impact.
2. Check whether the issue affects one user or several users.
3. Review recent failed-attempt evidence without collecting the password.
4. Use the approved unlock workflow; never disable MFA as a shortcut.
5. Remove stale saved credentials from the affected client.

## Validation and escalation

Ask the user to complete a fresh sign-in. Escalate repeated or unusual failures as a possible security event.
